冷蔵庫シェフ（FridgeChef）

冷蔵庫の写真から食材を読み取り、4人家族の夕食の献立（主菜・副菜・汁物）を3組提案する、家族向けの iPhone アプリです。 読み取りと献立づくりには、Anthropic 社の AI「Claude」を API で使います。

できること
冷蔵庫の写真（最大5枚。冷蔵室・野菜室・冷凍室などを分けて撮れる）から食材を読み取り、一覧にする（自信のない物には「要確認」の印）
一覧の確認・修正・追加（確認を飛ばして献立に進むこともできる）
主菜・副菜・汁物の献立を3組、短い一覧で提案。気に入らなければ出し直し
選んだ1組の買い足しリスト・材料（4人分）・段取り・作り方
「AI本体で相談する」：依頼文を作り、Claude・ChatGPT・Gemini などのアプリに渡す（料金はかからない）。食材の確認画面からは献立3組、献立の画面からは A・B・C 案それぞれの格上げや、週末のごちそう・主役の一品・ジャンル指定を相談できる
「いつもある物」（主食・調味料など）の登録。毎回自動で加え、買い足しに出さない
今月の使用額と残高の目安を表示
使用量の日報メール（GitHub の自動実行。基準額を超えたら警告と対処の手順）
使うのに必要なもの
Claude Console（platform.claude.com）のアカウントと API キー。チャットで使う claude.ai とは別のサービスで、claude.ai のプラン（無料・有料）に関係なく、API の料金が別にかかります（Max・Ultra・Team プランには毎月の API クレジットが含まれます）。
前払い：Console で先にクレジットを購入し、使った分が差し引かれます。自動補充はオフをおすすめします。
料金：やりとりした量（トークン）で決まります。
モデル	入力 100万トークンあたり	出力 100万トークンあたり
Claude Haiku 5.5（初期設定）	0.10 ドル	0.50 ドル
Claude Sonnet 5.5	2.00 ドル	10.00 ドル
料金（ドル）＝ 入力トークン ÷ 1,000,000 × 入力単価 ＋ 出力トークン ÷ 1,000,000 × 出力単価
料金（円）  ＝ 料金（ドル）× 為替（1ドル何円か）

目安：1回の献立づくりで、Haiku なら約0.3円、Sonnet なら約5円（1ドル＝150円、2026年11月の料金で試算。税金は含まず、実際の額は Console で確認）。

インストール：ipa は署名していないので、SideStore や LiveContainer などで入れます。
